§01

概述与设计支柱

一句话定位：把"完成待办事项"转化为"孵化怪奇生物"的自我驱动工具。待办是真实的，生物是虚构的，动机是真诚的。

用户在一个虚拟工作间里照看每周降临的怪奇生物蛋。完成现实中的待办事项会为蛋注入孵化点，逐步揭露蛋中生物的特征；拖延与失约会增加孵化畸变的风险。孵化完成的生物入册成为图鉴收藏——每一只都由随机特征组合而成，全世界不会有第二只一模一样的。

目标用户：需要外部动机结构的自驱工作者与学生；对生成式收集（每只都独一无二）有天然好感的收藏型玩家。平台：Web 应用，桌面优先、移动端自适应，可常驻浏览器标签页或固定为 PWA。

支柱一

未知即奖励

完成待办的回报不是数字上涨，而是揭开一小块未知。奖励的核心情绪是好奇心，不是成就感——好奇心比成就感更抗疲劳。

支柱二

失败不清零

拖延的代价是"孵出不完美的东西"，而不是"什么都没有"。任何一颗蛋都有结局，任何结局都入册。用户永远没有弃坑的理由。

支柱三

随机而自洽

特征随机抽取，但蛋的主题、槽位互斥与联动规则保证每只生物看起来像"一种生物"，而不是零件的堆砌。怪，但怪得成立。

与同类产品的差异：Habitica 用数值成长驱动打卡，Forest 用损失厌恶驱动专注，Finch 用照顾宠物驱动自我关怀。本作的差异点是生成式收集——完成待办的每一步都在揭晓一个不可预知、不可重来的孵化结果，把待办清单变成开盲盒的过程。
§02

核心循环

STEP 1
获得蛋
上一枚蛋孵化完成或入棚休眠后，新蛋即刻降临
→
STEP 2
全周 · 完成待办
按难度获得孵化点，逾期与失约累积风险
→
STEP 3
逐步揭露
每 12 点揭露一个特征槽，从剪影到细节
→
STEP 4
满 100 点 · 判定
依风险值判定正常孵化或畸变孵化
→
STEP 5
入册
生物记入图鉴或标本室，工作间迎接下一枚蛋

↺ 孵化完成 / 入棚休眠即领新蛋 · 周一结算休眠（见 §06）

蛋的获取是事件驱动的（v0.2 修订，原为每周一固定发放）：上一枚蛋孵化完成、或在周一结算中移入休眠棚的瞬间，新蛋即刻降临——提前孵完不用空等。节奏仍锚定自然周：休眠结算与强制孵化都发生在周一。一枚蛋需要 100 孵化点，对应大约 8～12 条普通粒度的待办；做得快就孵得多，做得慢的蛋进休眠棚，风险缓慢上涨。

循环里有两股方向相反的力：风险来自拖延（逾期、失约、休眠），惩罚指向"孵出畸变体"；惊喜来自投入（完成高难度待办提升变异率、按时连击提升稀有度）。用户逃避的事情让蛋变糟，用户攻坚的事情让蛋变好——动机的指向始终与"把该做的事做掉"一致。

§03

工作间（主界面）

工作间是唯一的主场景：一个单屏的、有生活气的小房间，视觉基调是"温暖的博物学者工作室"——木桌、暖灯、玻璃罩、墙上钉着的图鉴残页。所有功能都物化为房间里的物件，不做抽屉式菜单。

  • 孵化台（中央）：当前的蛋躺在孵化灯下。蛋是状态的可视化载体：进度越高微光越亮、偶尔透出内部剪影；风险越高壳上裂纹与暗斑越多。点击蛋查看已揭露的特征卡。
  • 待办板（左侧）：钉在软木板上的便签就是待办清单。新建、勾完成、标失败都在这里。临近截止的便签边缘会微微卷起变黄。
  • 休眠棚（右侧）：三格铺着干草的架子，存放未孵完的蛋。每格显示进度与当前风险。
  • 图鉴（桌上的厚册子）：点击翻开进入图鉴场景（§10）。
  • 驻场生物：默认由最近孵化的一只留在工作间里闲逛，也可在图鉴中指定任意一只驻场（再点一下取消指定、恢复跟随最新）。按性格特征播放行为动画（怯懦的躲在桌下、好奇的凑到屏幕前）。这是特征系统的日常展示窗口，也是情感黏性的主要来源。
设计意图：工作间必须"值得回来看一眼"。用户每天打开它的第一动机可以只是看看蛋亮了没有、驻场的小东西在干什么——待办的完成顺势发生，而不是被逼着面对清单。
§04

蛋与主题原型

新蛋在上一枚蛋离开孵化台的瞬间降临：孵化完成，或周一结算移入休眠棚（v0.2 修订，原为每周一固定发放）。主题从主题池随机抽取，未收集过的主题权重翻倍，保证收藏广度自然铺开。休眠棚满时蛋留在台上继续孵化，不需要顺延队列。

主题是"随机而自洽"的第一道保险：它决定了配色板、各特征槽的偏向权重和命名词根，让孵出的生物带有可辨认的生态气质。抽取规则见 §07。

§05

待办系统

待办是用户自己的真实事务，系统不生成虚构任务。字段刻意精简：标题、难度、截止日（可选）、备注（可选）。随时可添加，添加即挂上待办板。

5.1难度与孵化点

难度由用户自评。不做反作弊——这是自驱工具，自欺的损失由用户自己承担；相反，把大事拆成多条小待办是被系统鼓励的行为（拆分本身就是 GTD 的正确姿势）。

难度孵化点参考粒度
轻松+515 分钟内可完成：回一封邮件、预约、跑腿
普通+10一小时级或单日任务：写周报、整理素材
困难+20需要攻坚的多日任务：做完季度预算、修完一个模块
史诗+35周级大事：交付一个里程碑、搬家

5.2待办的三种离场方式

  • 完成：立即结算孵化点并触发揭露检查。逾期后补完成仍给全额孵化点（此前累积的逾期风险保留）——永远值得把事做完。
  • 主动放弃：用户删除一条未完成的待办，视为放弃，风险 +6%。给用户一个诚实的退出通道，代价温和。
  • 自动失败：逾期满 7 天仍未处理，自动标记失败，风险 +12%。避免"挂着一条烂待办永远不面对"。

5.3常用模版（重复性事务，v0.2 落地）

日常型工作（写日报、整理知识库、运动健身）与习惯性作息（每周户外、阅读、清理邮件）通过常用模版一键钉上：模版记录标题、难度与期限规则（今天 / 明天 / 本周内→自动算到周日 / 无期限），写便签弹层顶部一排模版小签，点一下即上板。手写便签可勾选"存为常用模版"（期限规则按所填截止日自动归纳），模版可删、同名覆盖、上限 12 条。

5.4线索信箱（外部待办源，v0.2 落地）

采集脚本定时分析本机的 git 仓库（最近提交与未提交改动）、Claude / Codex 会话记录（AI 提炼），以及 Jira（自建 Server，按 JQL 拉取当前用户未完成 issue，优先级映射难度、duedate 透传为建议截止日；哈希掺 ISO 周——忽略过的 issue 若仍未完成，下周重新送达），投进工作间墙上的线索信箱（有新信升红旗）。建议不直接上板——逐条人工审阅，采纳（可调难度与截止日）后才钉上黑板：黑板必须始终是"你亲手钉上的真实事务"。哈希去重保证同一线索（含已忽略的）不会重复送达。

5.5按时连击（正向激励）

连续 3 条待办按时完成后进入连击状态：在连击期间揭露的特征，稀有度权重提升（稀有 ×1.5、传说 ×2）。逾期或失败即断连击。风险是鞭子，连击是糖——两者分别盯住"别拖"和"按时"。

实现决议（v0.2b）：无截止日的待办不计入也不中断连击。为使加成即时生效，特征改为揭露瞬间掷定并立即存档（刷新依然无法重掷）；孵化判定骰、畸变预案、变异骰、命名词根仍在蛋生成时注定——结局早已注定，长成什么样取决于路上的表现。

6.2畸变风险

风险值决定孵化判定时畸变的概率。基础 3%，上限 85%——任何一颗蛋都保有至少 15% 的正常孵化可能，绝境里也留一线希望。

此后每日 +2%		单条待办的逾期风险上限 +12%

6.3孵化判定与变异

达到 100 点时： roll(0–100) < 风险值 → 畸变孵化，入标本室（§10） 否则 → 正常孵化，继续变异判定 ↓ 变异率 = 5% 基础 + 本蛋期间每完成一条困难/史诗待办 +1% （上限 15%） roll 命中 → 从变异表（§07.6）中抽取一条，惊喜揭晓

注意方向设计：畸变率只被拖延行为推高，变异率只被攻坚行为推高。变异是荣誉——它记录着这只生物是被多少条硬仗喂大的。

6.4休眠规则

  • 周一结算时，孵化台上未满 100 点的蛋自动移入休眠棚（上限 3 枚），进度与风险全部保留，新蛋随即降临；棚满则蛋留在台上继续孵化。
  • 用户可随时把休眠蛋与孵化台上的蛋手动交换——孵化点只进当前孵化台上的蛋。
  • 休眠每满一周风险 +8%；休眠满 3 周强制进行孵化判定（以当前已揭露的特征孵化，未揭露的槽位随机补全但不展示揭露演出）。

§07

特征系统（特征库）

特征系统是本作最核心的内容资产。生物由 8 个特征槽组成，每槽从对应特征池中抽取一条。首发特征库共 103 条特征 + 8 条变异 + 6 条畸变，理论组合数超过 4 亿（未计配色与变异）。

7.1抽取规则

  • 稀有度基础权重：普通 70% · 稀有 25% · 传说 5%。按时连击期间稀有 ×1.5、传说 ×2（§05.3）。
  • 主题偏向：每个蛋主题为部分槽位指定"主题池"（§04 表中的特征偏向）。抽取时 70% 概率从主题池中抽，30% 从该槽全量池中抽——保证主题气质明显，又留有跨界惊喜。
  • 互斥规则：部分特征组合在生理上不成立，抽取时后抽的槽位剔除冲突项。示例：飘浮无足 ↔ 弹簧腿/蹼足；无口 ↔ 长卷舌；雾缘 ↔ 硬质甲壳。
  • 联动规则：部分特征会拉高其他槽位相关项的权重，制造"讲得通的巧合"。示例：无眼 → 纹样「眼状斑」权重 ×3（它身上长满了不是眼睛的眼睛）；金属冷光 → 异能「静电」×3；伞盖形 → 附肢「触手束/纤毛裙边」×2；夜行 → 异能「微光」×2。

§08

揭露演出

揭露是本作的核心奖励时刻，演出规格要对得起"开盲盒"的期待，但必须短——它嵌在真实的工作流里，不能变成打断。单次揭露全程 4 秒内，可跳过。

  1. 触发：勾掉待办的瞬间，孵化点飞入蛋中，蛋抖动、微光增强。若跨过阈值，进入揭露。
  2. 揭晓：蛋内剪影闪现一瞬，随后弹出特征卡——正面是特征名、示意图与稀有度框色（普通灰 / 稀有蓝 / 传说金），翻面是一句风味文本（即 §07 各表的描述列）。
  3. 沉淀：特征卡收进蛋侧的卡槽栏。未揭露的槽位显示为带"？"的卡背，用形状暗示但不剧透。
  4. 日常反馈：已揭露的特征反映在蛋的外观上——揭露了荧光脉络的蛋，壳上会透出脉络的光。让进度"看得见"。

孵化判定（100 点）是全篇最大的演出：孵化灯全亮、蛋壳龟裂、破壳瞬间黑屏半秒——然后生物完整登场，变异（若有）在此刻才揭晓。畸变孵化的演出同规格但配乐转为温柔的小调：破壳后它有点不知所措，工作间的灯光为它调暗了一档。

§09

命名系统

孵化完成时系统生成一个两字本名：主题词根 + 特征词根。主题词根来自蛋主题（§04 表），特征词根取自该生物已揭露特征中稀有度最高的一条（每条特征在数据中预置一个"命名字"字段）。

示例： 深海蛋 ＋ 雾缘（命名字·霭） → 「汐霭」 菌沼蛋 ＋ 收藏癖（命名字·莞） → 「菌莞」 机械蛋 ＋ 弹簧腿（命名字·簧） → 「匣簧」

本名之外，用户可以随时起昵称（图鉴中并列展示）。档案编号 GSI-001 起顺序累加，永久不变——编号是"你孵化生涯"的时间轴。

10.1收集驱动

  • 特征收集率：103 条特征各自是否"见过"。未见过的特征在图鉴附录中显示为剪影，是最直接的收集牵引。
  • 主题完成度：每主题分册的收集格数。
  • 变异收集：8 条变异各自是否拥有，图鉴中单独一页金边展示。

10.2标本室

畸变体入图鉴末尾的独立分册"标本室"——深色纸页、手写体标签，气质安静而温柔。畸变体档案额外记录"它经历了什么"（哪些待办的逾期与失约推高了风险）。标本室有自己的完成度统计：畸变收集是合法的收集线，但因为畸变体的特征槽会被覆盖 1～2 个，靠故意摆烂刷畸变的收集效率永远低于好好做事——系统在结构上保证了"失败可收集，但不划算"。

§11

长线扩展（v0.2+）

  • 周挑战蛋：偶尔降临带条件的特殊蛋，如"本周完成 3 条困难待办则保底一条稀有特征"。把周目标游戏化。
  • 生态羁绊：集齐同主题 5 只解锁该主题的隐藏蛋（第 11 种主题的入口）。
  • 双驻场：工作间同时驻留两只生物，性格特征之间产生互动动画（恶作剧的藏起洁癖的收藏品）。
  • 分享卡：把任意一格档案导出为图片，含立绘、特征清单与"由 N 条待办喂大"——天然的传播素材。
  • 年度报告：每年一页"孵化年鉴"：今年你用 412 条待办孵化了 37 只生物，最难的一周喂出了唯一的传说特征。
  • 音景：工作间环境音随驻场生物的异能变化（消音领域=近乎无声，低鸣安神=白噪音）。
§12

MVP 范围

MVP 的验证目标只有一个："揭露驱动完成待办"这个循环是否真的成瘾。一切不服务于此的内容后置。

12.1做

  • 3 个蛋主题：深海、菌沼、幽影（气质差异最大的三个）。
  • 特征库：每槽全部普通级 + 每槽精选 2 条稀有级（约 60 条），传说级与变异表留到 v0.2。
  • 完整的待办系统、孵化点、风险与孵化判定、休眠棚。
  • 工作间单场景 + 驻场生物（性格动画先做 6 种普通性格）。
  • 图鉴与标本室（含"由 N 条待办喂大"档案行）。
  • 揭露演出的简化版：特征卡弹出 + 蛋外观变化，破壳演出可以先用静态分镜。

12.2不做

  • 账号系统与多端同步（localStorage + 手动导出存档顶住）。
  • 反作弊、社交、分享卡、音效音景、移动端深度优化。
  • 按时连击（数值层的锦上添花，验证期噪音）。
§13

技术方案与数据结构

13.1技术栈

  • 纯前端 SPA，纯单机形态：Vite + React + TypeScript，无后端。npm run release 产出单文件 release/怪奇生物孵化器.html（JS/CSS 全内联），双击 file:// 直接运行，无需任何服务器；localStorage 持久化 + JSON 存档导出/导入（注意 file:// 与 localhost 存档按浏览器源隔离，迁移走导出/导入）。字体经 Google Fonts 加载，离线时优雅降级到系统字体。
  • 生物渲染：SVG 分层部件拼装。每条特征对应一组可换色矢量部件；生物 = 特征 ID 列表 + 主题色板，渲染是纯函数，完全可复现。图层顺序：躯干 → 表皮效果 → 纹样 → 附肢 → 头部 → 口器 → 特效层（变异、异能微粒）。部件绘制走 Figma/Illustrator 导出 SVG 的管线，代码侧只做组装与换色。
  • 时间处理：逾期判定用本地自然日；每周刷新锚定 ISO 周（周一 00:00 本地时间）。打开应用时补结算离线期间的风险与周事件。
  • 随机性：所有抽取用带种子的 PRNG。孵化判定骰、畸变预案、变异骰在蛋生成时注定；特征在揭露瞬间掷定（由蛋种子 + 槽位 + 连击状态决定）并立即存档——两者都无法靠刷新重掷，"命运感"与连击激励并存（见 §05.3 实现决议）。

§14

开放问题

  • 难度自评的通胀：长期使用后用户可能把一切标成"困难"换变异率。是否需要软约束（如每周困难+史诗总数上限），还是信任用户？倾向后者，观察 MVP 数据再定。
  • 外部待办源：已部分落地（§05.3 线索信箱：git + AI 会话采集）。滴答清单 / Things / 日历等结构化源的接入仍待评估。
  • 孵化后的养成层：目前生物孵化即入册，仅一只驻场。是否需要喂养、互动等养成玩法？倾向不做——养成会稀释"孵化揭露"的核心，且带来负罪感（忘喂），违背支柱二。
  • 美术产能：103 条特征 × 部件适配是最大的内容成本。SVG 部件是否可以先用参数化几何风格（扁平剪纸感）压低单条成本，验证循环后再提美术规格？
  • 周节奏与假期：长假周待办骤减，蛋大概率休眠。是否需要"休假模式"（冻结风险）？倾向需要，一个开关即可，防止假期回来面对一棚高危蛋的挫败感。
