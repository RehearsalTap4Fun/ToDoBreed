§01

项目概况与当前状态

纯前端单页应用，无后端、无账号。把"完成真实待办"转化为"孵化随机特征生物"的自驱工具（详见设计文档 v0.1，仓库归档于 docs/design-v0.1.html）。

维度当前状态（2026-08-21）
功能MVP 闭环全部可玩：待办 → 孵化点 → 揭露 → 判定 → 图鉴/标本室，含休眠棚、事件化领蛋、驻场生物、场景化工作间
内容3 主题（深海/菌沼/幽影）、8 槽位 77 条特征（含传说级 18 条）、6 条畸变、8 条变异
画风造型已完成"可爱治愈"深化；5 种渲染风格可切（默认贴纸卡通），主风格待定稿
质量npm run build 通过（tsc 严格模式 + vite），npm test 25/25 通过
启动npm install && npm run dev
§02

技术选型

选型方案理由
框架Vite + React 18 + TypeScript（strict）轻、快、类型兜底；单人 side project 迭代效率优先
持久化localStorage + JSON 导出/导入MVP 不做账号与同步；导出档防丢、防换机
渲染参数化 SVG 分层部件生物 = 特征 ID 列表的纯函数渲染，完全可复现；画风做在滤镜层，特征零重画切换
随机mulberry32 带种子 PRNG蛋生成瞬间命运固定，刷新不可重掷（命运感 + 防刷）
测试Vitest（纯逻辑层）引擎全部纯函数，时间以参数注入，天然可测
依赖面运行时仅 react/react-dom零 UI 库、零状态库、零图表库，降低长期维护成本
§03

系统架构与数据流

核心原则：引擎层全部纯函数。UI 不直接改状态，所有变更走 engine.ts 的纯函数，返回新状态 + 事件列表；副作用（存档、弹窗、Toast）集中在 App.tsx 的 absorb() 一处。

INPUT
用户操作 / 时间流逝
完成待办、放弃、换蛋；跨日与周一由 processTime 补结算
→
ENGINE
纯函数引擎
completeTodo / processTime …→ 新 GameState + GameEvent[]
→
ABSORB
副作用汇聚点
saveState 持久化；事件分流：揭露/破壳进弹窗队列，其余进 Toast
→
RENDER
React 渲染
工作间 / 图鉴 / 弹窗；生物与蛋由纯函数 SVG 组件绘制
  • 时间注入：引擎函数一律接收 today: 'YYYY-MM-DD' 参数，不内部取时钟——这是可测试性与 dev 时间偏移的基础。
  • 事件驱动演出：GameEvent（reveal / hatch / eggArrived / autoFail / forcedHatch / noEgg）由 UI 排队消费，一次完成跨多个阈值时揭露卡按序弹出。
  • 离线补结算：processTime 从 lastDay 逐日推进到今天，每日先处理周一事件再结算逾期，保证多日离线后的风险与周事件顺序正确。

§05

核心机制实现要点

5.1命运预掷 + 揭露懒掷（draw.ts）

预掷（蛋生成时，seed 固定）：孵化判定骰（0–100）、畸变预案（1–2 条）、变异骰、命名词根。懒掷（v0.2b 决议）：8 个特征改为揭露瞬间掷定并立即存档——结果由 (蛋种子, 槽位, 连击状态) 决定，互斥/联动从已揭露特征即时重算，连击加成得以生效且刷新依然无法重掷。休眠强制孵化时未揭露槽位静默补掷（无加成）。

// 揭露顺序（先形体后灵魂）
frame → limbs → head → mouth → surface → pattern → temperament → quirk
// 每槽：70% 主题池 / 30% 全量池 → 稀有度权重 N70:R25:L5 ×（连击时 R×1.5 / L×2）× 联动倍率

5.2时间结算（engine.processTime）

  • 逐日循环 lastDay+1 … today；每日先判 isMonday 走周事件，再结算逾期。
  • 周一：休眠棚每蛋 dormantWeeks++ 且 +8% 风险，>3 周强制孵化；台上未满蛋入棚（入棚即 +8%）并随即降临新蛋；棚满则蛋留台继续孵化。
  • 逾期：首日 +4%、此后每日 +2%，单条待办累计上限 12%；逾期满 7 天自动判失败再 +12%。风险落在结算当日孵化台上的蛋。
  • 事件化获取（v0.2 修订）：孵化完成即刻降临新蛋，顺延队列已移除；processTime 兜底"空台即领"，孵化台理论上不再空置。

5.3孵化判定

aberrant = destiny.judgmentRoll < egg.risk   // 判定骰在蛋生成时已注定
// 畸变 → 套用预案畸变（1–2 槽被覆盖），入标本室；正常 → 完整入册
// 档案快照 fedTodos（标题+难度），图鉴的"由 N 条待办喂大"由此而来

5.4周与日的边界处理

日戳统一 YYYY-MM-DD 字符串（本地日期生成、UTC 解释运算，避开 DST）；周以"该周周一的日戳"为标识。App 每 60 秒调一次 processTime，跨零点与跨周一在应用常开时也能触发。

§06

渲染管线与画风

6.1生物渲染器（Creature.tsx）

生物 = 特征ID×8 + 主题色板 + seed 的纯函数。图层顺序：

地影 → 异能微光 → 附肢 → 蒙版躯体(底色/渐变 + 纹样 + 表皮内效 + 体积光 + 肚皮布片)
     → 表皮外饰 → 头部与眼 + 腮红 → 口器
  • 蒙版技巧：躯体剪影画进 <mask>，纹样/材质/光影以整幅矩形绘制后被剪影裁切——蛇形等描边型剪影也能统一处理。
  • 造型基准（可爱治愈）：大头身比、圆润无锐角、大眼双高光、全员腮红、粉彩化配色（底色向白偏移 16%、暗部收敛）。
  • 畸变渲染：错位=器官偏移、未成形=槽位半透明、色彩失谐=失谐色板、静默=无动画、外溢=模糊、逆生长=整体缩放。

6.2五种画风（滤镜层，特征零重画）

画风实现定位
flat 扁平剪纸纯色块面基线对照
soft 软立体径向渐变 + 高光/体积影 + feDropShadow安全耐看
sticker 贴纸卡通feMorphology 双层膨胀（深描边+白贴纸边）+ 提饱和当前默认，表情包/分享气质
ink 水彩图鉴feTurbulence 位移抖动轮廓 + 墨线环 + 纸纹颗粒乘算博物志氛围，宜纸面场景
plush 毛绒玩偶噪声凹凸 + feDiffuseLighting 绒面 + 双重扰动毛边 + 缝线布片；脸部件独立于绒面（塑料眼+刺绣脸）实体陪伴感，候选主风格
滤镜层经验：光照/乘算类滤镜会洗淡颜色，尾部需补饱和（plush 补了 saturate 1.28）；发光大色块（异能微光）必须放在描边滤镜组之外，否则半透明 alpha 会被膨胀出脏环；「双目下垂」类表情用闭眼「˘˘」曲线才治愈，半睁眼读作不耐烦。

6.3蛋渲染器（Egg.tsx）

主题化外观（深海气泡/菌沼活蘑菇/幽影眨眼暗涡）+ 状态可视化：微光强度 ∝ 孵化点，裂纹分档出现于风险 >15/30/50/70%，≥60 点透出内部剪影。蛋的可爱化改造尚未做（见路线图）。

§07

数据结构

单一存档对象存于 localStorage key gsi-save-v1，含 version 字段供后续迁移。要点：

GameState { version, gsiCounter, seedTick, saveSalt,   // 存档级随机盐
            currentEgg, shed[≤3],
            todos[], codex[], lastDay, firstDay }

Egg   { id, theme, seed, points, risk, destiny,        // 命运在生成时已注定
        dormantWeeks, fedBy[] }
Todo  { id, title, difficulty, due?, state, riskFromOverdue }   // 单条逾期风险上限 12
CreatureRecord { id "GSI-001", name, nickname?, traits×8,
        aberrations[], outcome, riskAtHatch, fedTodos快照, forced }

待办永不物理删除（状态机 open/done/abandoned/failed），图鉴档案另存 fedTodos 标题快照双保险。

§08

测试

tests/engine.test.ts，12 条，全部针对纯逻辑层（渲染层靠画风实验室目检）：

  • 时间：周一锚定、跨月日差。
  • 抽取：3 主题 × 300 seed 扫描——8 槽必满、互斥必守、同 seed 可复现；命名不撞字。
  • 数值：难度给点与阈值揭露；逾期 4+2+2… 封顶 12；满 7 天自动失败 +12；放弃 +6。
  • 判定：判定骰 ≥/＜ 风险的正常/畸变双路径，档案快照正确。
  • 周循环：入棚 +8 与新蛋降临、休眠满 3 周强制孵化、手动换蛋。
约定：改 engine.ts / draw.ts / time.ts 必须跑 npm test；新机制先补测试再实现（逾期、休眠这类时间逻辑最容易错在边界日）。

§11

已知问题与约定

  • 无 git 仓库：项目尚未 git init。建议尽早初始化并做首次提交（参照斗蛐惯例可直接在 main 上开发，代价是提交前测试必须全绿）。
  • 版本升级迁移：存档带 version，加字段时在 storage.loadState 做向后兼容填默认值，不清档。
  • 风险归属：逾期风险落在结算当日台上的蛋；台空则该日风险落空（对用户有利，接受）。
  • 驻场时段动画：夜行性格按本地时钟 20:00–6:00 切换行为，纯展示层，不进存档。
  • 性能：图鉴卡片多时 SVG 滤镜（尤其 plush 的光照）有开销，图鉴内已关 idle 动画；若入册量大再考虑虚拟滚动或缩略图缓存。
  • 设计文档同步：数值改动需回写设计文档（Artifact 同链接重发 + docs/design-v0.1.html 同步），避免两份文档漂移。
