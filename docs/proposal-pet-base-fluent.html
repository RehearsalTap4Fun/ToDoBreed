Fluent 混合试验

把 Microsoft Fluent Emoji（MIT）的猫、狗、兔 Flat 版拆成路径、按角色换成我们的基因色，套到同一个坐姿身体上。四列并排：v2 母版、Fluent 原脸、Fluent 头壳加我们的六层眼、v2 头壳加 Fluent 五官。看哪一部分值得借。

A · v2 母版
B · Fluent 原脸换色
C · Fluent 头壳 + 六层眼 + 明暗
D · v2 头壳 + Fluent 鼻嘴
猫Fluent 猫脸：圆角方头、尖角耳、张口笑
狗Fluent 狗脸：方头、三角垂耳、大块浅色吻、吐舌
兔Fluent 兔脸：圆头、长耳、倒三角鼻、裂唇门牙、胡须

逐件判断

借的是曲线和结构，不是整张脸。下表按部件判断，绿色进母版，红色不进。

部件来源判断理由
猫头壳Fluent cat_face不进圆角方头是 emoji 语法，把整只猫拉向表情符号。v2 的圆头带腮更接近目标画风
猫张口笑Fluent cat_face进表情库下唇弧线和口腔色块干净有力，作为「阔阔笑口」的嘴型直接可用（D 列）
狗头壳与垂耳Fluent dog_face不进方头加三角耳，狗味足但方；耳朵的下垂曲线可作 v2 垂耳的修正参考
狗鼻嘴舌Fluent dog_face进鼻头形、人中线、吐舌三件成组，比 v2 的椭圆鼻更像狗（D 列）
兔鼻裂唇门牙Fluent rabbit_face进倒三角鼻加裂唇加两颗门牙是兔子的标志组合，v2 的版本弱于它（D 列）
兔胡须Fluent rabbit_face进两侧各两根短须，兔和猫都可以用
六层眼v2 母版保留Fluent 的豆豆眼没有表情容量，C 列换上六层眼后立刻有神
Color 版明暗Fluent Color参考径向渐变加底部压暗的思路与 v2 三层明暗一致，可借其边缘柔化程度
结论
  • D 列是要的答案。头壳和身体留 v2，鼻嘴从 Fluent 借。三种底型里兔和狗提升最明显，猫多了一种笑口。
  • 整脸移植不划算。Fluent 是 emoji 语法，方头豆豆眼一上身就不像卡通宠物。C 列证明换上我们的眼睛能救回来，但头形仍然偏方。
  • 许可干净。MIT，改造与商用皆可，署名 Microsoft Fluent Emoji 即可。
