宠物底型

把怪奇生物先锚在猫、狗、兔这些人人认得的宠物上，再在它们身上做一两处特异化。熟悉的陌生感，而不是无边界的陌生。

今天提出的判断是：现在生成的怪奇生物太开放，看了带入不进去。我把 gen2 现有的目录、合成策略和验收图翻了一遍，这个判断成立，而且能说清楚它为什么会这样、改成什么样、怎么改。v2 已按当天拍板结果更新：首发猫、狗、兔；走现有母体加物种套件；物种进图鉴；姿态以宠物猫狗最常见的坐姿为基准。

结论先行
  1. 诊断成立，根因有三处。体型槽的 5 个特征全是「团 / 豆 / 滴」这种抽象软形，没有一个指向某种生物；12 个动机槽各自独立随机，每只都是从零发明的新物种；主题退化成了色板。没有参照就没有反差，怪也就没有落点。
  2. 方案：物种进体型槽，主题变怪化词库，强特异封顶。第一次揭露先告诉你「是只猫」，后面七次揭露回答「这只猫哪里不一样」。首发猫、狗、兔三种底型，每只至少保留物种四个识别锚点中的三个。
  3. 实现推荐走 B 路线。不新做四足母体，在现有团子 / 双足 / 浮游三个母体上补「物种套件」部件（头、耳、吻、尾、纹样），生成器零改动，用它已有的 lockedSelections 锁物种。先做猫 × 三母体的验证合成，通过再扩狗、兔。姿态以常见坐姿为基准：biped 母体承载坐姿（基准），blob 母体承载团子，floating 母体承载浮。

物种锚点
  • 体型槽没有物种。frame 槽的五个特征是圆团体、宽云体、豆豆双足体、高软双足体、浮滴体。它们描述的是「一团软的东西」，不是任何一种生物。这一槽本该是整只生物的基模，现在是空的。
  • 十二个动机槽独立随机。眼、嘴、口内、头饰、手、脚、尾、额外附肢、表皮、纹样、特效逐槽掷骰。每一只都是完全新的物种，于是第三只和第一只在观感上没有区别。当所有东西都随机时，随机本身就没有信息量了。
  • 主题只剩色板。深海、菌沼、幽影目前主要落在配色和少数部件的权重上。看图很难说出「这只是深海的」，主题没有成为可辨认的身份。
  • 名字带不进去。「汐灯」「菌斑」指向特征，不指向一个能想象出来的生物。

可爱与带入依赖同一个机制：先匹配到一个已知基模，再发现偏差。看到三角耳和胡须垫，人一眼归类为猫；下一刻发现它有三只眼，张力才出现。全然陌生的东西没有基模可以匹配，剩下的只是一堆有颜色的软体。设计支柱三写的是「怪，但怪得成立」，成立的前提是先有一个东西可以「不成立」。

§02

设计模型：底型 × 怪化 × 强度阀

底型是熟悉的来源。首发猫、狗、兔三种，每种有四个识别锚点，任何一只生物至少保留三个。低于三个，它就不再是这种动物，而是回到现在的状态。

底型锚点一锚点二锚点三锚点四先天纹样（弱特异）
猫三角立耳圆脸与胡须长尾坐姿虎斑 · 三花 · 燕尾服
狗垂耳吻部与鼻头吐舌上翘短尾单眼补丁 · 斑点 · 奶牛
兔长直耳门牙与 Y 鼻绒球短尾坐姿垂耳 · 荷兰白环

姿态基准（拍板补充）：以宠物猫狗最常见的正面坐姿为基准。头在上，胸腹直立，两只前爪并拢落地，后腿盘坐成左右两团，尾巴从身侧绕出。三个母体各承载一种姿态：biped 母体承载坐姿，是基准，N 级；blob 母体承载团子，即面包坐，N 级；floating 母体承载浮，R 级，幽影主题加权。物种套件在三种姿态上通用。

怪化是陌生的来源，由主题供词。主题不再是色板，而是「哪里长歪了」的词库。下表全部是 v0.3.0 目录里已有的部件，不需要新画。

§03

落到八个语义槽

不改槽位数量，不改揭露节奏。变的是每一槽「默认是什么」和「什么算特异」。

槽现在提案
frame 体型骨架圆团 / 宽云 / 豆豆 / 高软 / 浮滴物种底型 = 物种 × 姿态。坐姿猫（N，biped 母体）、团子猫（N，blob 母体）、浮猫（R，floating 母体），三物种共九条。物种在此槽揭露，是第一张揭露卡
headAndEyes 头部与眼头形、眼、头饰各自自由头形默认为物种头，是锚点。眼与头饰是特异候选：三珠眼、潮灯、菌伞、幽帽
mouth 口器嘴形 + 口内自由默认为物种嘴：猫的 w 嘴、狗的吻与舌、兔的门牙。口内细节算弱特异
appendage 附肢手 / 脚 / 尾 / 额外附肢自由手脚默认为物种爪。尾是锚点，换成鱼尾、菌簇尾算强特异。额外附肢（鳍、翅、软带）算强特异
surface 表皮4 种自由默认短绒。凝胶、软鳞算强特异
pattern 纹样4 纹样 + 3 配色新增物种纹：虎斑、三花、奶牛、单眼补丁。主题纹（星点、孢环）算弱特异
personality / quirk6 + 6 条词条不动，文案按物种口吻改写：猫踩奶、狗摇尾、兔顿足

揭露与命名跟着变。第一槽揭露物种，揭露卡从「圆团体」变成「是只猫」，之后每一张卡回答「这只猫哪里不一样」，好奇心有了具体的问句。命名改成主题词根加物种字：汐喵、渊汪、菌兔、幽喵，最高稀有度特征退到副标题，比如「汐喵 · 提灯」。图鉴新增「品系」维度，三物种乘三主题九个格子。收集感从「61 条特征」变成「集齐九种宠物」，后者一眼能数清。

§04

实现路径

QMonster 的美术管线是锁定母体加逐槽 AI 生成，再过色键抠图和机器门禁。物种要进去，有四条路。

路径做法效果成本与风险
A 新四足母体猫、狗、兔各做一个锁定母体，全部部件补该母体变体最像真宠物，姿态最准目录校验要求结构件按母体出 exact 变体，现有 55 件都要补；生成器插槽是双足语义（arm / leg），四足要改渲染器。v0.1 到 v0.3 三个母体走了约 10 天，每加一个物种再来一遍
B 物种套件 推荐在团子 / 双足 / 浮游三个母体上加物种头、耳、吻、尾与物种纹坐姿猫、团子狗、浮兔本身就是成熟的宠物卡通语法，图版 Ⅲ、Ⅳ 已示意新部件约 28 件：坐姿躯干、前爪、后脚 3 件（biped 母体）；物种头壳与物种尾各 3 物种 × 3 母体共 18 件；物种嘴 3 件；物种纹 4 件。全部走现有提示词、色键、门禁管线，清单见附录。生成器零改动：孵化器按 seed 抽物种与姿态，经 lockedSelections 锁 bodyFrame / headShape / tail / mouthShape，母体随 bodyFrame 自动确定。风险是坐姿躯干是 biped 母体的新结构件，需先验证
C 古典 SVG 轨转向用孵化器自己的 SVG 渲染器画物种底型最快，当天出原型，file:// 可用，全程可控与 gen2 毛绒位图两种质感并存，等于搁置 gen2。适合做纸面验证，本文图版即是这条路的产物
D 只调参surpriseRatio 0.3 降到 0.15，maxStrongFeatures 2 降到 1，none 率上调减少混乱零成本，但只能减乱不能加熟，单独做不解决问题。作为 B 的一部分

推荐 B 加 D，顺序如下。

  1. 坐姿猫验证。先在 biped 母体上出坐姿猫（坐姿躯干、前爪、后脚、猫头壳、猫尾、猫嘴，特异为零），确认「一眼是坐着的猫」。再出 blob 团子猫与 floating 浮猫各一张。
  2. 目录升 v0.4.0。补猫套件 10 件与虎斑纹，收紧合成策略。旧生物的 spec 锁在 v0.3.0，按现有目录版本约定不受影响。
  3. 孵化器接线。spawnEgg 从 seed 派生物种与姿态；揭露映射改为第一槽即物种；hatch 时以 lockedSelections 锁套件；命名改物种字；图鉴加品系格。引擎仍是同步纯函数，改动都在 orchestrator 与映射层。契约见附录。
  4. 扩狗、兔。同一套流程各 7 件，加 4 件物种纹，届时九个品系格全部可收。

孵化器锁定契约。头壳（耳与脸）和姿态永远锁定，尾巴最多被主题替换一次，所以「四个锚点至少保留三个」是结构性保证，不需要额外校验。

// spawnEgg：全部从 qseed 派生，防刷新重掷
species  = pick(['cat', 'dog', 'rabbit'])                    // 等权
posture  = pick({ sit: 0.55, loaf: 0.35, float: 0.10 })      // 幽影主题 float 提到 0.25
keepTail = roll() < 0.70                                     // 三成允许尾巴被主题替换（强特异）

lockedSelections = {
  bodyFrame:  { sit: 'body_biped_sit', loaf: 'body_blob_round', float: 'body_floating_drop' }[posture],
  headShape:  `head_${species}`,
  mouthShape: { cat: 'mouth_cat_w', dog: 'mouth_dog_nose_tongue', rabbit: 'mouth_rabbit_teeth' }[species],
  ...(posture === 'sit' ? { arms: 'arms_front_paws', legs: 'legs_haunch_tuck' } : {}),
  ...(keepTail ? { tail: `tail_${species}` } : {}),
}
// 母体随 bodyFrame 自动确定（generate.ts lockedBodyRig）
// 揭露：第 1 槽 frame = 物种 + 姿态；命名 = 主题词根 + { cat: '喵', dog: '汪', rabbit: '兔' }
